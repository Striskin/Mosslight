# Mosslight: The Quiet Bell

A small, original woodland action RPG in C++17 and raylib 5.5. Restore a forgotten
shrine, soothe its guardian, and return the valley's song. All pixel artwork and
sound cues are generated by the game from original shapes and tones. No external
art assets, engine, ECS framework, scripting runtime, or additional game library.

## Windows: quick build

Install the **MSYS2 UCRT64** toolchain. In the MSYS2 UCRT64 terminal:

```sh
pacman -S --needed mingw-w64-ucrt-x86_64-gcc
```

Add `C:\msys64\ucrt64\bin` to your Windows PATH, then open PowerShell in this folder:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1 -Test -Smoke
.\build\Mosslight.exe
```

The script downloads a pinned official raylib 5.5 MinGW release on the first build,
checks its SHA-256, compiles the game and tests, copies data and the raylib license,
and updates `Whats_This.txt` with the actual result. `-Run` opens the game after
building. No CMake is needed for this route. The result statically links raylib
and the GCC runtime, so distribute `Mosslight.exe`, `data/`, and `RAYLIB-LICENSE.txt`
together. No MSYS2 installation is needed on the receiving Windows PC.

### CMake / Visual Studio alternative

Install Visual Studio's Desktop development with C++ workload and CMake. From a
Developer PowerShell prompt:

```powershell
cmake -S . -B build-vs -A x64
cmake --build build-vs --config Release
ctest --test-dir build-vs -C Release --output-on-failure
.\build-vs\Release\Mosslight.exe
```

CMake uses an installed raylib package or downloads raylib 5.5 source. Windows,
Linux, and macOS code paths are provided, but only the Windows MinGW build has
been exercised here. CMake builds do not automatically edit the project memory;
update `Whats_This.txt` after using that route.

## Controls

| Action | Key |
| --- | --- |
| Walk in eight directions | WASD / arrow keys |
| Run | Hold Shift |
| Swing sword | Hold J / Z |
| Dodge, briefly invulnerable | Space |
| Talk, open, read, rest, advance dialogue | E |
| Confirm menu / advance dialogue / respawn | Enter |
| Drink tonic, restores 3 hearts | Q |
| Satchel and equipped gear | Tab / I |
| Quest journal and route guide | M |
| Pause / back | Escape |
| Save now | F5 |
| Mute sound | F10 |
| Borderless fullscreen | F11 |

The game pauses when it loses focus. Dialogue, menus, inventory, and the journal
pause combat. Resize freely: the 480x270 canvas uses integer scaling and black
letterboxing. Window size cannot be smaller than the virtual resolution.

## Your first journey

1. Talk to **Keeper Aven**, beside the village square. Open the welcome chest.
2. Go east into **Fernwake Wood**. Its eastern cache holds the **Ember Seed**.
3. Head south to **Stillwater Cave**. Find **Moon Dew** in its southeast chamber.
4. Optional: explore the forest's northwest **Wandering Hollow**. Its far southeast
   room has a **Copper blade**, which doubles sword damage. Room templates,
   connecting paths, encounters, and supply loot use your saved world seed.
5. Trade four glow fragments with **Talla the Weaver** in Hearthmere for a coat.
   It adds two maximum hearts. Gear equips automatically.
6. Go north from the forest to **The Quiet Bell Shrine**, offer the relics at its
   bowl, then rest at the shrine lantern. The northern seal is now open.
7. Face the **Hollow Warden**. Amber lines telegraph a charge, rings telegraph a
   volley. Its attacks accelerate below half health. Dodge, then strike during
   recovery. You may retreat south. Return to Aven after victory for the ending.

Lanterns restore all hearts, set your respawn checkpoint, and save. Death returns
you to the last lantern with your inventory and quest intact. Regular enemies
and an undefeated boss reset when a region is reloaded. Opened chests stay open.
There is no penalty or time limit, and no required grind for the relic quest.

## Saves

On Windows: `%LOCALAPPDATA%\Mosslight\journey.sav`. One save slot. New journey asks
before replacing it. Autosaves occur at new game, region transitions, chest loot,
quest changes, lanterns, respawn, and clean exit. F5 and the pause menu also save.

Saves include region, position, health, inventory/equipped gear, quest flags,
opened chest IDs, checkpoint, elapsed play time, and cave seed. The format is
versioned, size-limited, value-validated, checksummed, and atomically replaced.
A valid previous save is retained as `.bak` and recovered if the primary fails.
The checksum detects accidental corruption, not intentional save editing.

```powershell
.\build\Mosslight.exe --save .\build\my-test.sav --mute
.\build\Mosslight.exe --smoke-test --captures .\build\captures
```

Smoke mode uses a separate save and never touches your normal journey. It renders
all regions and key screens, captures PNGs, exercises respawn and load, and exits.

## Code and data

| Module | Responsibility |
| --- | --- |
| `main` | raylib lifetime, input, focus, command line, visual smoke harness |
| `game` | screens, interactions, quest orchestration, one active region |
| `player`, `collision` | movement, facing, dodge, safe swept tile movement |
| `enemies`, `combat` | distinct AI, boss phases, projectiles, sword hits, damage |
| `inventory`, `dialogue` | items, automatic equipment, conversations and objectives |
| `maps`, `procedural` | strict map parsing, deterministic connected template cave |
| `save` | validated snapshots, atomic persistence and backup |
| `render`, `ui`, `audio` | original pixel art, camera, screens, generated sounds |
| `tests/tests.cpp` | simulation and persistence regression checks, no framework |

`data/maps/*.map` are handcrafted ASCII grids with explicit exits, objects, and
enemy spawns. `scripts/author-maps.ps1` is an optional offline authoring utility;
the runtime never runs it. `data/rooms.txt` contains 11x9 cave templates.
`data/items.txt` and `data/enemies.txt` define item descriptions and enemy tuning.

Tiles: `.` grass/floor, `+` trail, `,` flowers, `:` shrine stone, `_` bridge,
`*` crystals, `T` solid trees, `#` solid rock, `~` solid deep water,
`H` solid house footprint, `P` solid pillar. Objects use tile-center coordinates.

## Scope and next milestone

This is a complete first slice, not a full-length RPG. Six connected regions,
one quest chain, two ordinary enemy species, one two-phase boss, two gear upgrades,
one seed-stable cave, and a short ending. Buildings are decorative exteriors.
No controller support, remapping, multi-slot saves, authored soundtrack, or
long-term enemy persistence yet. Enemies use local steering, not pathfinding.

Most valuable next milestone: human playtests of the complete quest and boss,
then tune reach, telegraphs, travel time, and rewards before adding more content.
Read `Whats_This.txt` before editing and update it after code work and builds.

Raylib reference: [official 5.5 release](https://github.com/raysan5/raylib/releases/tag/5.5)
and [API reference](https://www.raylib.com/cheatsheet/cheatsheet.html).
